# golazo-site

Landing site for Golazo, an agent-payable World Cup 2026 data API on Injective.

**Live site:** https://golazo.pxxl.run/
**Project repo:** https://github.com/nevodesigns/golazo

Static HTML, CSS, and vanilla JS in the engineering drawing sheet style shared with the NevoForge site and the NEVO Designs portfolio. Deployed on Pxxl, served with `serve`.
